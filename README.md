# 📊 Sales View Report – Software Accessories

## 📌 Overview
This repository contains a **Power BI Sales View Report** analyzing Net Sales (NS $), Gross Margin (GM $), and Gross Margin % across regions, markets, customers, and product segments.  
The dashboard provides actionable insights into performance trends from **2019–2022 (Est.)**, helping stakeholders evaluate profitability and growth opportunities.

---

## 🌍 Regional & Market Insights
- **Regions Covered**: APAC, EU, LATAM, NA, USA, India, China, Canada, Spain, Philippines, South Korea, Norway, UK, Italy, France.
- **Net Sales (NS $)**: Ranges from $0.0bn to $0.8bn across regions.
- **Gross Margin (GM $)**: Key contributors include USA and India.
